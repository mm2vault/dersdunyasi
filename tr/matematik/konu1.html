📘 Cebir - Denklem Çözümü

Birinci ve ikinci dereceden denklemleri çözmek

📖 Konu Anlatımı

1. Birinci Dereceden Denklemler

ax + b = 0 şeklindeki denklemleri çözmek için:

  • Sabit terimi diğer tarafa al
  • x'in katsayısına böl
  • Sonuç: x = -b/a

2. İkinci Dereceden Denklemler

ax² + bx + c = 0 şeklindeki denklemleri çözmek için diskriminant kullan:

  • Δ = b² - 4ac (Diskriminant)
  • x = (-b ± √Δ) / 2a

3. Örnek Soru Çözümü

Soru: 2x² - 5x + 3 = 0 denklemini çöz

Çözüm:

  • a = 2, b = -5, c = 3
  • Δ = (-5)² - 4(2)(3) = 25 - 24 = 1
  • x₁ = (5 + 1) / 4 = 1.5
  • x₂ = (5 - 1) / 4 = 1
