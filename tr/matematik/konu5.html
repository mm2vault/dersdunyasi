1. İntegral Tanımı

İntegral, türevin ters işlemidir.

  • Belirsiz İntegral: ∫f(x)dx = F(x) + C
  • Belirli İntegral: ∫[a,b] f(x)dx = F(b) - F(a)

2. İntegral Kuralları

  • ∫x^n dx = x^(n+1)/(n+1) + C
  • ∫dx = x + C
  • ∫cf(x)dx = c∫f(x)dx
